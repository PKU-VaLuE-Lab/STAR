Abstract

Vision-language-action models (VLAs) map language instructions and visual observations to robot actions, showing strong capabilities across robotic manipulation tasks. However, in a probing experiment, we find that action representations near the action output do not fully preserve task-relevant visual grounding. Motivated by this late-layer grounding gap, we introduce STAR, for STeering Action Representations, a training-free inference method for pre-trained VLAs.

STAR applies an exponential moving average over late-layer residual updates, allowing later action representations to inherit object-aware update directions from earlier layers without model updates or architectural changes. It further uses recent proprioceptive states to adapt the mixing strength, using conservative mixing when execution dynamics change rapidly. Experiments on robot manipulation benchmarks show that STAR improves late-layer object awareness and increases average task success rates by 4.0 percentage points.

Method

STAR leaves the first two-thirds of the Transformer unchanged. Across the final third, it maintains an exponential moving average of residual updates, so each late layer combines its current update with the update trend accumulated from preceding layers. This helps visual evidence formed earlier persist until action decoding. Recent proprioceptive states adjust the mixing strength at every control step.

Training-free residual steering

Let Δhtk be the residual update produced by late layer k. STAR combines this current update with the accumulated update trend mtk−1. The resulting trend mtk replaces the original update passed to the next layer. A single coefficient βt is used throughout the forward pass at control step t.

mtk = βtmtk−1 + (1 − βt)Δhtk
  1. Keep early layers unchanged. They form language-conditioned visual evidence.
  2. Mix late-layer updates. The EMA helps this evidence persist across depth.
  3. Adapt during execution. Mixing is stronger during steady progress and more conservative during rapid transitions or fine adjustments.

Analysis

We analyze π0.5 on LIBERO-PRO with two complementary diagnostics. Object masking tests whether replacing task-object pixels with the image's mean RGB value changes the hidden states used for action generation. Input-gradient saliency (Simonyan et al., 2013) tests whether those pixels influence the final predicted action. We also inspect attention maps to determine whether the hidden-state effect appears as a visible change in attention allocation.

Masking-based object awareness

We run the model on an original image and on a paired image in which the task-relevant object's pixels are replaced with the mean RGB value of the full image. At each layer, object awareness is the normalized L2 change in the action hidden state. A larger value means that removing the object's visual evidence has a stronger effect on the representation used to generate actions.

To check that the score is not merely responding to generic image corruption, we use two controls: the same number of masked pixels scattered randomly across the image, and a similar-area rectangle sampled from the background.

Action-gradient dependence on the task object

The masking experiment measures hidden-state sensitivity. We next test whether the final predicted action actually relies on the task object. We differentiate a scalar score derived from the predicted action chunk with respect to the input image, then measure the fraction of total input-gradient magnitude that falls inside the task-object region. A higher score means that the selected action depends more strongly on pixels belonging to the key object.
